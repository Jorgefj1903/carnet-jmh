# Carnet digital JMH

Plantilla web del carnet digital de socio de la Asociación Cultural Escuela de Jota María de Huerva.
No contiene datos de socios: la página consulta un servicio de Google Apps Script con el token personal
de cada socio (el token va en el enlace del email) y solo recibe nombre, número, año de alta,
DNI parcial y actividades.
